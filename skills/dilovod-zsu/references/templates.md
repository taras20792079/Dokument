# Текстові заготовки 15 видів документів

Це структури для чернеток, не затверджені бланки. Застосовуй разом із
[матрицею](requirements.md), [доступом](access.md) і [чек-листом](checklists.md).
Квадратні дужки — поля для заповнення, а не факти. Індекси надає реєстратор.
Розташування тексту тут не засвідчує відповідність друкованого файла.

## 1. Рапорт

```
Командиру [найменування військової частини]
[звання у давальному] [Ім'я ПРІЗВИЩЕ у давальному]

РАПОРТ

[Заголовок — якщо передбачений застосовною формою]

Прошу [конкретне прохання, потрібні дати й підтверджені обставини].
або: Доповідаю, що [факти].
[Підстава / додатки — якщо є]

[Посада автора]
[Військове звання] [особистий підпис] [Ім'я ПРІЗВИЩЕ]
[Дата]
```

Не обмежуй рапорт клопотанням: можливі доповідь і повідомлення. Умови відпустки
або іншого права не встановлюються самим шаблоном.

## 2. Службова записка

Спершу перевір допустимість документа за п. 1.8 Інструкції. «Через службу
діловодства» не є самостійним дозволом листування між підрозділами.

```
[Автор / бланк за формою]
[Адресат]
СЛУЖБОВА ЗАПИСКА
[Дата] [індекс після реєстрації — якщо застосовується]
Про [питання]

[Суть питання, підтверджені факти, потрібне рішення]

[Посада] [звання за формою] [особистий підпис] [Ім'я ПРІЗВИЩЕ]
```

## 4. Пояснювальна записка / пояснення

Назву добери за застосовним порядком, не перейменовуй документ автоматично.

```
[Адресат]
[Автор — за формою]
[Назва виду документа]

[Виклад події у хронологічній або причинно-наслідковій послідовності]
[Відомі автору причини й обставини; припущення відокремлено]

[Посада за формою] [звання] [особистий підпис] [Ім'я ПРІЗВИЩЕ]
[Дата]
```

## 5. Донесення / звіт

Форму, періодичність, склад показників і адресата визначає відповідний табель або
спеціальний регламент. Для зовнішньої чернетки не запитуй реальні оперативні дані.

```
[Найменування автора]
[ДОНЕСЕННЯ або ЗВІТ: конкретний вид]
за [період / станом на час]
[Дата] [індекс після реєстрації]

1. [Розділ за встановленою формою]
2. [Розділ за встановленою формою]
[Додатки]
[Уповноважений підписант: посада, звання, підпис, ім'я ПРІЗВИЩЕ]
```

## 6. Наказ

Спершу визнач категорію: основна діяльність, особовий склад, стройова частина,
адміністративно-господарська, мобілізаційні питання тощо. Перевір повноваження
і спеціальний порядок. Зміни № 183, № 251, № 2 враховуй за [реєстром](sources.md).

```
[Найменування видавця]
НАКАЗ
[Дата] № [індекс після реєстрації]
[Місце видання за формою]
Про [питання]

[Преамбула — підстава/мета за потреби]
НАКАЗУЮ:
1. [Розпорядча дія; виконавець і строк, якщо це завдання]
2. [Наступний пункт]
[Пункт про контроль — коли потрібний для цієї категорії]

[Посада уповноваженого командира]
[Звання] [особистий підпис] [Ім'я ПРІЗВИЩЕ]
```

Не вигадуй підстави, призначення або факт ознайомлення. Установлений стройовий
шаблон не замінюй загальною управлінською структурою.

## 7. Заявка на використання автомобільної техніки

Робоча карта полів із вихідного пакета, а не підтверджений додаток 9. Перед
нормативною видачею отримай первинний бланк і точні реквізити спеціального наказу.

| Група | Поля для звірення з оригіналом |
|---|---|
| Підстава і вантаж | № з/п; підстава й мета; найменування; кількість з одиницею |
| Техніка | Марка машини/причепа; військовий номер; кількість рейсів |
| Рейс | Маршрут; довжина; старший машини; водій; дата і час виїзду/повернення |
| Оформлення | Замовник і підпис; рішення про виділення; примітки; передбачені підписанти |

Не конвертуй літери військового номера між абетками без документальної перевірки.
Склад підписантів, 15 граф, можливість поєднання ролей і призначення старшого машини
перевіряй за чинним оригіналом, а не за «типовою практикою».

Для списання майна, розслідування або інших спеціальних процедур потрібна їхня

[Місце]
засідання [назва колегіального органу]

Секретар — [дані]

1. [Питання і доповідач]

Не вигадуй хід засідання, голосування або кворум. За регламентом може бути стислий
протокол; не вимагай вигаданих виступів для заповнення розділу.

## 13. Директива

Документ відповідного органу військового управління. Спершу встанови рівень
видавця, компетенцію, предмет, режим доступу й спеціальний порядок погодження.
Не генеруй «офіційну директиву ВЧ» за загальним шаблоном наказу. За відсутності
регламенту надай лише погоджену з користувачем структуру проєкту з плейсхолдерами.

у чаті за накладене доручення.

## 15. Витяг з наказу / протоколу

```
[Автор оригіналу]
ВИТЯГ З [НАКАЗУ / ПРОТОКОЛУ]
[Дата і номер оригіналу]
[Заголовок / вступні реквізити оригіналу за формою]
[Дослівно потрібна частина із збереженням нумерації]
Оригінал підписав(ли): [посади, звання за формою, імена ПРІЗВИЩА]

Згідно з оригіналом
[Посада особи, що засвідчує] [особистий підпис] [Ім'я ПРІЗВИЩЕ]
[Дата засвідчення; печатка за застосовною вимогою]
```

Без тексту оригіналу не створюй вигаданий витяг. Для наказу не копіюй блок
«голова/секретар» із протоколу. Не імітуй особисті підписи оригіналу.
