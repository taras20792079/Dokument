# Кадрові й особисті форми

Довідки видавай за встановленою для мети формою. Текстове наближення не є
затвердженим бланком. Перед файловим оформленням отримай оригінал застосовної форми
з чинної Інструкції або перевіреного спеціального акта; джерела — [sources.md](sources.md).

| Документ | Що встановити перед складанням |
|---|---|
| Довідка про проходження служби, орієнтир «форма 5», п. 2.8.4.3 | Чинний текст, вид служби, дані особи, найменування частини, мета, підписант, дата/індекс і печатка за формою |
| Довідка про участь, орієнтир «форма 12», п. 2.8.4.1 | Правова мета, точне найменування заходів, підтверджені періоди й підстави; не підмінювати довідки для різних пільг/статусів |
| Інші довідки | Номер форми за метою, а не за припущенням; чинний додаток |
| Посвідчення про відрядження, п. 2.8.8.3 | Особа, підстава, строк, мета, пункт призначення; відмітки прибуття/вибуття не вигадувати |
| Припис, п. 2.8.9 | Вид припису, наказ-підстава, місце й строк прибуття, уповноважений підписант |
| Відпускний квиток, п. 2.8.9 | Вид і період відпустки, наказ, місце проведення й вимоги чинної форми |
| Графік відпусток | Категорія осіб, календарний період, підстави й погодження |
| Обхідний лист | Установлена форма, перелік служб, реальні відмітки; не стверджувати відсутність боргу без підтверджень |

Повноваження підписанта перевір за чинним п. 2.7.19 та конкретною формою. Не
встановлюй універсально «начальник стройового» чи «начальник кадрового органу»
для будь-якого документа з подібною назвою.

Усі ПІБ відтворюй за формою; спеціальна форма може потребувати по батькові.
У вільному підписному блоці використовуй власне ім'я ПРІЗВИЩЕ. Не змінюй точний
текст спеціальної форми заради загального стилістичного правила.

Категорії наказів звіряй з п. 2.3.4 Інструкції, а не з неіснуючим пунктом у SKILL.md.
Зміни 2025–2026 років наведені в реєстрі; старі номери додатків не переносити.
