# Перевірка перед видачею

Спільне: факти з наданих даних; застосовна форма й редакція; повноваження;
стадія за [матрицею](requirements.md); гриф за [access.md](access.md);
незаповнені поля; відсутність вигаданих підписів, індексів та нормативних підстав.

| Вид | Додатково перевірити |
|---|---|
| Рапорт | Адресат, автор, ясна суть прохання/доповіді, дати й підстави, підписний блок; права не виводяться з самого шаблона. |
| Службова записка | Допустимість внутрішнього листування; належний маршрут, без вигаданих винятків. |
| Доповідна | Встановлені факти, наслідки, обґрунтовані пропозиції, відокремлення припущень. |
| Пояснювальна/пояснення | Правильний вид за процедурою, хронологія, лише відомі автору обставини. |
| Донесення/звіт | Табель/спеціальна форма, період, узгоджені показники, мінімізація оперативних даних. |
| Наказ | Категорія, компетенція, актуальні зміни, підстава, точні розпорядчі дії, погодження за категорією; контроль за потреби. |
| Автозаявка | Первинний бланк, кількість і назви граф, одиниці, дати/час, дані техніки, реальні підписанти. |
| Акт | Спеціальна форма, підстава, укладачі/комісія, факти, висновки в межах компетенції, належні підписи, затвердження за формою. |
| Протокол | Засідання, дата, учасники, реальний порядок денний і рішення, підписи за регламентом; не вигадувати виступи. |
| Довідка | Підтверджуваний факт, відповідна форма, належний підписант, печатка за вимогою. |
| Лист | Немає назви «ЛИСТ»; адресат, зв'язок із вхідним, ясний предмет, додатки, підпис і виконавець за вимогами. |
| Розпорядження | Компетенція видавця, конкретні завдання і строки, правильна форма розпорядчої частини. |
| Директива | Рівень органу, спеціальний порядок, компетенція й режим доступу; загального шаблона недостатньо. |
| Доручення | Зв'язок із підставою за потреби, виконавець, результат, строк; електронна резолюція відрізняється від тексту проєкту. |
| Витяг | Є оригінал, дослівність, нумерація і реквізити оригіналу, належне засвідчення, правильний склад підписантів. |

Для DOCX додатково: поля й формат; стилі й шрифти; колонтитули кожної секції;
таблиці; нумерація; відсутність накладань; підпис не відірвано від тексту;
файл реально створено і візуально перевірено. Для електронного оригіналу окремо
перевіряється підпис/печатка засобами системи, а не виглядом DOCX.

Результат перевірки формулюй за обсягом виконаного: мовна редактура, структурна
перевірка, звірення конкретної форми або конкретних норм. Не обіцяй юридичної
чинності всього документа лише на підставі цього чек-листа.
