# Матриця реквізитів і стадій

Це алгоритм перевірки, а не заміна затверджених форм. Джерело вимоги визначай за
[реєстром](sources.md). Спеціальну форму перевіряй першою, загальні вимоги — далі.

| Елемент | Проєкт | Підписаний/зареєстрований документ |
|---|---|---|
| Автор, найменування ВЧ | Залежно від виду і бланка; у рапорті автор визначається підписним блоком | Звір із застосовною формою та бланком |
| Назва виду | Для листа окрему назву «ЛИСТ» не додавай; інші — за видом/формою | Перевір точну назву |
| Дата | Дата користувача або `[дата підписання]`; для акта/протоколу врахувати подію | Зіставити з підписанням/подією, не змінювати ретроспективно |
| Індекс | `[індекс після реєстрації]` за потреби; автор його не вигадує | Перевірити дані реєстратора/СЕДО та потік |
| Заголовок | За видом; не нав'язувати без перевірки спеціальних винятків | Звірити застосовну вимогу і текст |
| Адресат | Для адресованих документів; належний відмінок | Повноваження і правильність адресування |
| Текст | Лише підтверджені факти, мета і прохання/рішення | Відповідність підставам і відсутність неузгоджених змін |
| Підпис | Посада, звання за формою, `[особистий підпис]`, ім'я ПРІЗВИЩЕ | Уповноважений підписант; для електронного — перевірка підпису |
| Затвердження | Окремий блок, якщо потрібний для конкретного документа | Не підміняти підписом автора |
| Печатка | За застосовним правилом, не за звичкою | Наявність/необхідність перевіряти окремо від підпису |
| Додатки | Реальні назви й кількість; невідомий обсяг — плейсхолдер | Звірити фактичні вкладення, аркуші/примірники |
| Гриф/колонтитули | Рішення про режим доступу та [access.md](access.md) | Перевірка всіх сторінок |

Огляд за видами:
- Рапорт/особиста записка: автор, адресат, суть, дата, підпис; реєстраційні й інші
  реквізити перевіряй за видом, формою та стадією, а не за абстрактним «мінімумом».
- Наказ/розпорядження: видавець, категорія, повноваження, підстава за потреби,
  заголовок, розпорядча частина, виконавці й строки там, де є завдання, підпис.
- Акт/протокол: підстава або подія, учасники, дата/місце за формою, факти/рішення,
  належні підписи; затвердження за застосовним регламентом.
- Лист: бланк/автор, адресат, дата/індекс за стадією, відповідь на вхідний за потреби,
  текст, підпис, додатки й виконавець за вимогами; не друкуй назву виду «ЛИСТ».
- Довідка/кадровий документ/заявка: реквізити насамперед визначає спеціальна форма.
- Витяг: реквізити оригіналу й дослівна потрібна частина; засвідчення відокремлене
  від підписів оригіналу.

У висновку явно розрізняй: відсутнє в проєкті / має заповнити реєстратор /
не застосовується / помилка за підтвердженою нормою / ще не підтверджено.
