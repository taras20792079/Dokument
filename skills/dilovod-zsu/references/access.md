# Гриф доступу та колонтитули

Джерела: [реєстр](sources.md), наказ № 2 від 02.01.2026 і подальший № 77 від 27.02.2026.
Нижче — робоча консолідація лише перевірених змін пп. 2.7.11, не всіх правил ДСК.

## Результат поєднання двох змін

- Позначення за пп. 2.7.11: «Відкрита інформація» або «Для службового користування».
- На першій сторінці: праворуч у верхньому полі над адресатом/грифом затвердження,
  з відступом 104 мм від межі лівого поля; додатково посередині нижнього поля
  із застосуванням колонтитула.
- На решті аркушів: посередині верхнього і нижнього полів із застосуванням колонтитулів.
- Для відкритої інформації за потреби в нижньому полі додається позначка поширення.
- Верхнє позначення на першій сторінці за потреби доповнюється даними за актами,
  які регулюють документообіг інформації з обмеженим доступом.
- Наказ № 77 вилучив винятки для організаційно-розпорядчих документів, рапортів,
  посвідчень про відрядження, відпускних квитків, приписів, довідок, аркушів
  погодження й обхідних листів. Не відтворюй цей список як чинні винятки.
- Тим самим наказом вилучено окремий абзац 7 пп. 2.7.11 про оформлення грифа ДСК
  організаційно-розпорядчих документів за пп. 15.5.2; не використовуй вилучений
  абзац як чинну підставу винятку. Інші спеціальні вимоги ДСК перевіряй окремо.

## Застосування

1. Встанови належний режим доступу з наданого авторизованого контексту; не визначай
   відкритість лише за відсутністю грифа. Коли рішення не відоме — залиш плейсхолдер.
2. Перед оформленням звір, чи немає пізніших змін і спеціальних вимог.
3. У текстовій чернетці зазначай поза її основним текстом, які колонтитули потрібні;
   пробіли в Markdown не є перевіркою геометрії сторінки.
4. У DOCX налаштовуй окремий верхній колонтитул першої сторінки, нижній для всіх
   сторінок та верхній для наступних. Перевір секції, альбомні сторінки й сумісне
   розміщення грифа та номера сторінки без накладання.
5. Секретні грифи не є варіантами для автоматичного вибору цим скілом.
