# Умовні приклади

Усі імена, частини й обставини нижче вигадані. Перенось лише структуру; реальний
зміст бери з даних користувача. Це приклади тексту проєктів, не офіційні бланки.
Реквізити за стадією: [requirements.md](requirements.md); гриф і колонтитули:
[access.md](access.md); перевірка всіх видів: [checklists.md](checklists.md).

## Рапорт про відпустку — без припущення про право і тривалість

```
Командиру військової частини А0000
полковнику Івану ІВАНЕНКУ
РАПОРТ

Прошу надати мені [вид відпустки] за [період] тривалістю [кількість] діб
з [дата] з проведенням у [місце — якщо потрібно за формою].
[Підстава та додатки за наданими даними]

Командир взводу
лейтенант [особистий підпис] Петро КОВАЛЕНКО
[Дата]
```

## Доповідна про несправність

```
[Автор / бланк за формою]
Командиру військової частини А0000
полковнику Івану ІВАНЕНКУ
ДОПОВІДНА ЗАПИСКА
[Дата] [індекс після реєстрації — за порядком]
Про виявлену несправність обладнання

Доповідаю, що під час огляду [дата] генератор [позначення] не запустився.
Причину несправності не встановлено.
Пропоную організувати діагностику уповноваженими фахівцями та визначити
необхідні заходи за її результатами.

[Посада] [звання] [особистий підпис] Сергій БОНДАРЕНКО
```

## Акт — збереження меж компетенції

```
[Гриф затвердження за спеціальною формою]
[Автор]
АКТ
[Дата] № [індекс після реєстрації]
Про огляд обладнання
Підстава: [реальна підстава]
Комісія у складі [склад] оглянула [об'єкт] і встановила: [факти].
Висновок у межах повноважень: [підтверджений висновок].
[Розподіл примірників за формою]
[Підписи належних укладачів]
```

Не перетворюй цей приклад на акт списання без спеціального порядку.

## Лист-запит

```
[Бланк військової частини А0000]
[Дата] № [індекс після реєстрації]
Командиру [умовна частина]
полковнику Василю МЕЛЬНИКУ
Про надання технічної документації

Для організації ремонту [об'єкт] просимо надати [конкретна документація].
Додаток: [фактичне вкладення — якщо є].

Командир військової частини А0000
полковник [особистий підпис] Іван ІВАНЕНКО
[Виконавець і службовий контакт]
```

Потребу листування й адресування перевір за Інструкцією. Немає вигаданих вихідних
номерів, висновків про списання, підписів або факту реєстрації.
